SEC-002 · Sales enablement · v1.1 · June 2026 · Companion to SEC-001

Positioning

Lazarus v1 is a deal autopsy engine for stalled pipeline — deterministic scoring on uploaded calls, not a rep note-taker or CRM. Customer data is not used to train public AI models.
Not Gong/Chorus/ChatGPT. Lazarus autopsies one stalled deal and outputs a rescue script in ~60 seconds.
Buyer: VP Sales / Sales Manager — triage tool for recoverable vs dead deals.

Security at a glance

Zero model trainingGemini API — zero retention configuration; no public model training on customer content
EncryptionTLS 1.3 in transit · AES-256 at rest (Supabase) · raw audio processed in memory only
Tenant isolationPostgreSQL RLS — per-user rows when Supabase Auth is enabled; service role server-side only
RetentionDefault 30-day purge of raw transcript text; analysis metadata retained
Recording consentCustomer warrants legal right to upload (Terms §2) — Lazarus does not record calls
