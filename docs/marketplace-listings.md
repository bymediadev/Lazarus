# Marketplace listings (widget loadout)

Website account first, then store enable. The widget is Lazarus Deal Recovery in the meeting — same Recovery Brief.

1. Sign in on [getldr.ca](https://www.getldr.ca).
2. Connect Zoom, Google Meet, or Microsoft Teams on the Live tab or Account.
3. Enable **Lazarus Deal Recovery Widget** in the Chrome Web Store, Zoom Marketplace, or Teams store.
4. **Open widget as this account** mints `/portal?widget=zoom|meet|teams&launch=` so the host does not ask for a second login.

Listing URLs (when published): `VITE_CWS_LISTING_URL`, `VITE_ZOOM_MARKETPLACE_URL`, `VITE_TEAMS_STORE_URL`.
